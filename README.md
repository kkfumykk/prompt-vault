# AI Prompt & Art Gallery (Public Edition)

X（Twitter）のフォロワー獲得と、PixAI自動回収プログラムの販売（マネタイズ）に特化した一般公開用AI画像＆プロンプトギャラリー。

## 特徴
- **ソーシャルロッカー**: プロンプトに鍵をかけ、Xフォロー＆ポストで即時解禁・コピー可能。
- **PixAI自動回収ツール販売CTA**: トップバナーおよびモーダル内に販売リンク（Tips/note等）を自動掲載。
- **推奨生成環境モーダル**: モデル、サンプラー、設定値の解説ポップアップ。
- **マスター管理ダッシュボード**: ブラウザ上で画像の登録・削除、PixAI販売URL、Xアカウント設定、パスワード変更が可能。
- **独立設計**: 個人用Vault（ポート8000）とはポート（8080）もデータも完全に分離。

## 起動方法
`run_public.bat` をダブルクリック（http://127.0.0.1:8080 で起動）。

初期管理者パスワード: `admin`（管理画面から変更可能）

## テスト実行
```bash
.venv\Scripts\python.exe -m pytest -v
```
